# Agente DAGMA

Assistente de posicionamento de cultivares DAGMA (uso interno Agro Amazônia).

## Arquivos
- `index.html` — tela + motor do agente (alterações de comportamento vêm por patch neste arquivo)
- `base_dagma.js` — base de dados: cultivares, posicionamento por região e municípios (substituir quando o portfólio mudar)
- `robots.txt` / `.nojekyll` — bloqueio de indexação e configuração do GitHub Pages

## Atualizar
Arraste o arquivo novo pra cá (Add file → Upload files) e confirme o commit. O site atualiza em 1–2 minutos.
